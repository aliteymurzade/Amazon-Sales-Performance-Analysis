# 📊 Amazon-Sales-Performance-Analysis

Bu Power BI hesabatı **Handex** tərəfindən təqdim olunan praktiki tapşırıq əsasında hazırlanmışdır. Layihənin məqsədi real 
e-ticarət datası üzərində tam funksional, interaktiv və vizual olaraq cəlbedici bir analitik dashboard-un qurulmasıdır.
